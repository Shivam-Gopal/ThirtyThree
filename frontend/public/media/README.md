# media/ — drop your files here

| Folder                         | What goes in it                                             |
| ------------------------------ | ----------------------------------------------------------- |
| `logos/clients/`               | Client logos shown in the "Logos - on board" marquee        |
| `logos/brand/`                 | ThirtyThree brand logo files                                |
| `videos/pov/`                  | "Our POV" reels                                             |
| `videos/ads/`                  | "We make ads" reels                                         |
| `images/posters/`              | Poster frame for each video (shown before the video loads)  |
| `images/work/`                 | Thumbnails for the Sample Work cards                        |
| `case-studies/<slug>/`         | Images used inside each case-study page                     |

After adding a file, register it in `src/data/content.ts` (one array entry) and it shows up on the site.
